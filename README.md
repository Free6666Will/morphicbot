---

## 🌟 Architecture Overview

- **Cloud Intelligence Tier**: Google Cloud Vertex AI & Gemini Live encrypted WebSockets (WSS) for real-time duplex speech, visual contextual reasoning, and emotional companion dialogue.
- **Edge Compute Tier**: Rockchip RV1126B (Forlinx OK1126B-S) running a native Rust daemon (`robotd`) with hardware NPU/ISP video processing, local face detection, and DoA sound angle localization via a ReSpeaker/XVF3800 microphone array.
- **Physical Embodiment**: Dual 1.28-inch GC9A01 circular LCD eye displays (SPI) and a 3-wheel holonomic omnidirectional chassis (Ø142mm base, L-type 520 geared motors).
- **Spatial Intelligence**: Bio-inspired adaptive spatial network simulations for dynamic corridor generation and obstacle avoidance.
